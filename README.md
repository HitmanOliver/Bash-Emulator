# Bash эмулятор на python (Этап 1)  
## Описание функций и настроек  
### Функции  
1) *EnterHandleProcessi* - обработка нажатия клавиши Enter  
2) *TwindowInit* - инициализация gui окна  
3) *lsProcess* - обработка команды ls  
4) *cdProcess* - обработка команды cd  
5) *CommandHandleProcess* - обработка и анализ введенной команды и аргументов  
6) *OutputWrite* - вывод ответа командной оболочки   
### Константы  
1) TWindowW = 1000 - ширина окна  
2) TWindowH = 800 - высота окна 
3) InputPadX = 8 - отступы поля ввода  
4) InputPadY = 8 - отступы поля ввода
5) Commands = 'ls', 'cd', 'exit' - команды оболочки   

## Запуск программы    
```BASH
python EmuBash.py
```
